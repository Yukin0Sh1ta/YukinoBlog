promise是ES6提供的一个对象，是用来解决异步编程的一种方式，可以将异步操作以同步操作的流程表达出来，避免了层层嵌套的回调函数。promise类似是一个容器，里面保存着某个未来才会结束的事件的结果
1.ES6里promise对象是一个构造函数需要用new进行实例，因为promise的值通常不做修改一般用const进行定义
const promise = new Promise((resolve,reject)=>{})
Promise()中需要添加一个函数作为参数，而这个函数里又需要添加resolve和reject作为两个参数
resolve()里用于保存操作执行成功的结果，反之reject()里用于保存操作执行失败的结果
举个例子我想要异步加载一张图片
function loadImgAsync(url) {
        const promise = new Promise((resolve, reject) => {
          var img = document.createElement("img");
          img.src = url;
          img.onload = () => {
            resolve(img);
          };
          img.onerror = () => {
            reject(new Error("图片加载失败，url有误" + url));
          };
        });
        return promise;
      }
这里先创建一个封装了异步加载图片的函数，函数里面实例了一个promise对象并返回，promise里通过img.onload保存到一个函数里，加载成功后则会执行函数里的内容，反之通过img.onerror加载失败后执行对应操作
之后在body里创建一个<div id="box">图片加载中...</div>元素，再通过box来获取这条元素
var box = document.querySelector("#box");
loadImgAsync(
        "https://ts3.tc.mm.bing.net/th/id/OIP-C.R86aJ5pc3Fu1oGj9boecuAAAAA?w=130&h=108&c=7&qlt=90&bgcl=1a112e&r=0&o=6&dpr=1.3&pid=13.1",
      )
        .then((data) => {
          box.innerHTML = "";
          box.appendChild(data);   
          console.log("图片加载成功");
        })
        .catch((error) => {
          box.innerHTML = "图片加载失败";
          console.log(error);
        });
执行loadImgAsync()函数，通过promise的.then()和.catch()方法分别执行相应成功后和失败后的操作
