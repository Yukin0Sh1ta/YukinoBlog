1.var：
①函数级作用域
for(var i = 0;i<10;i++){}
只会定义一个i，且i的值一直再改变
②变量提升
console.log(i)
var i =0;
正常运行但是返回undefined
上述代码等同于
var i;
console.log(i)
i =0;
③可以重复声明
var i = 10;
var i = 20;
console.log(i) //20
2.let:
①块级作用域（花括号）
for(let i = 0;i<10;i++){}
会定义十个i，每个i的值不一样
②没有变量提升
③作用域内不能重复声明
3.const:
①块级作用域（花括号）
②（常量）声明后不能改变他的值
③定义时必须初始化一个值
const i = 0；
④没有变量提升
⑤作用域内不能重复声明
！！！！！！如果使用 let 或 const 声明全局变量，它们不会挂载到 window 上
